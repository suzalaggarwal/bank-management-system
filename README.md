# Bank Account Management System

A C++ based Bank Account Management System that allows users to create and manage bank accounts efficiently through a console-based interface.

## Features

* Create new bank accounts
* Deposit money
* Withdraw money
* Transfer funds between accounts
* View account details
* Transaction history tracking
* File-based data storage
* Savings and Current account support

## Technologies Used

* C++
* Object-Oriented Programming (OOP)
* File Handling
* STL (Vector, String)

## Project Structure

project DSA/

## How to Run

### Compile

```bash
g++ account.cpp -o bank
```


### Execute

```bash
./bank
```

On Windows:

```bash
bank.exe
```
